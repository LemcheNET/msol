# Security policy

Please report security problems privately through GitHub:
**Security → Report a vulnerability** on https://github.com/LemcheNET/msol.
Do not open a public issue for them.

msol never handles your password: you sign in on Microsoft's own pages inside
Microsoft Edge, and the sign-in is stored in Edge's profile on your computer.
Reports about Microsoft Edge or Microsoft 365 themselves belong with Microsoft.
